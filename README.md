# Round Taiwan Rally

TTA's round-the-island board game for the Taiwan flight-ticket sweepstakes.
Single-file game: `index.html` (vintage travel-poster style, desktop + mobile layouts,
Taiwan PASS integration, scenic detours, airline partner branding).

- `DEPLOYMENT.md` — hosting, Supabase backend, GA4 setup
- `assets/` — official TTA Taiwan PASS map + extracted island art
- `images/` — destination card photos (800×500), served via GitHub Pages

Play the current build via GitHub Pages once enabled: Settings → Pages → main / root.
